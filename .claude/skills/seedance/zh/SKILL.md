# Seedance 视频生成技能

字节跳动 Seedance 2.0/2.5 AI 视频生成模型综合技能指南。涵盖提示词工程、镜头语言、光影、多镜头叙事、API 集成及跨平台故障排除。

## 核心理念

三项原则贯穿所有交互：

1. **听见意图背后的感受。** 用户描述的是结果（"让它有家的感觉"），而非参数。将感受转化为制作语言；绝不把翻译工作推回给用户。
2. **保持故事连贯。** 在对话中维护状态：主体、模式、风格、引用素材、已确定的约束、之前失败的尝试。用户不应重复任何决定；新请求继承已构建的世界。
3. **与用户共同成长。** 对初学者说通俗语言，对专业人士用导演术语——并察觉同一用户在项目中从一者成长为另一者。表达方式可以调整，标准绝不降低。

## 快速入门

当用户想要创建 Seedance 视频时：

1. 询问创建目标 — 视频类型、情绪、时长
2. 询问已有素材 — 图片、视频、音频文件
3. 按下方结构撰写提示词
4. 简要说明你的选择理由
5. 提供变体 — 更简或更野的版本
6. 提醒约束条件 — 人脸限制和文件上限

对于简单的单片段请求，直接起草即可，无需对一次性片段运行完整分析流程。

## 输入约束

| 输入类型 | 上限 | 格式 | 最大体积 |
|----------|------|------|----------|
| 图片 | ≤ 9（2.0）/ ≤ 30（2.5） | jpeg, png, webp, bmp, tiff, gif | 每张 30 MB |
| 视频 | ≤ 3（2.0）/ ≤ 10（2.5），总时长 ≤ 15s（2.0）/ 30s（2.5） | mp4, mov | 每个 50 MB |
| 音频 | ≤ 3（2.0）/ ≤ 10（2.5），总时长 ≤ 15s（2.0）/ 30s（2.5） | mp3, wav | 每个 15 MB |
| **文件总计** | ≤ 12（2.0）/ ≤ 50（2.5） | — | — |

### 输出规格

- 时长：4–15s（2.0），4–30s（2.5）
- 分辨率：480p、720p（1080p、4K 规划中）
- 画幅比：`21:9` `16:9` `4:3` `1:1` `3:4` `9:16`
- 格式：MP4（默认），MOV（2.5，高色彩保真度）
- 原生音视频同步，自动生成音效/背景音乐

### 关键限制

- **上传图片中不得出现逼真人脸**（官方平台合规要求）
- 即梦/Dreamina 会自动拦截含逼真人脸的上传
- 引用视频素材时生成成本略高
- 优先上传对视觉效果或节奏影响最大的素材

## 生成模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **T2V**（文生视频） | 仅通过文本生成 | 无参考素材 |
| **I2V**（图生视频） | 让静态图片动起来 | 有参考图，需要可控输出 |
| **V2V**（视频生视频） | 重新风格化/诠释一段视频 | 迁移运镜、节奏 |
| **R2V**（参考生视频） | 多模态：图片 + 视频 + 音频组合 | 最大控制力，最佳质量 |
| **FLF2V**（首尾帧） | 两个关键帧之间插值 | 精确控制起始与结束 |
| **Edit**（视频编辑） | 保留源视频，修改单一图层 | 换角色、换服装、改背景 |
| **Extend**（延长） | 从已确认素材继续生成 | 延长片段、无缝衔接 |

### 各模式提示词要点

**T2V：** 用紧凑层级构建整个镜头。核心结构：主体 + 动作 + 场景 + 镜头 + 光影/风格 + 音频。每段保持一个可见节拍和一个终点。

**I2V：** 保留可见身份，添加动态。使用 `保持 @图1 完全不变`；仅描述动态、镜头、时间、变化、音频和保留约束 — 不要重新描述图片内容。

**V2V：** 迁移动态、镜头或节奏。使用自有/已授权引用素材。明确声明迁移角色。

**R2V：** 每种素材分配一个主角色。不要让一个参考图片同时控制身份、姿态、场景和风格。拆分角色：`@图1 控制角色身份，@视频1 控制动态参考，@图2 控制场景风格`。

**FLF2V：** 声明 `@图2 是最终视觉目标`。首帧到尾帧的逐步插值。

**Edit：** 声明 `@视频1 是源片段；仅修改 [具体元素]`。不要重写整个场景。

**Extend：** 正确路由延长请求。观察已确认片段的实际结束状态。时长设置 = 仅新生成部分的时长。

## @ 引用系统

Seedance 最重要的语法。使用 `@` 为每个上传素材分配角色。

### 语法

```
@图1 @图2 @图3 ...
@视频1 @视频2 @视频3
@音频1 @音频2 @音频3
```

### 角色分配

必须明确声明每个引用的作用：

```
@图1 是主角（身份锚点）。
@图2 是场景背景。
@视频1 提供镜头运动参考。
@音频1 是背景音乐。
```

### 各场景素材分配策略

| 使用场景 | 图片 | 视频 | 音频 | 总计 |
|----------|------|------|------|------|
| 产品广告 | 4（产品各角度） | 1（镜头参考） | 1（音乐） | 6 |
| 角色动画 | 3（角色 + 场景） | 2（动态参考） | 1（音乐） | 6 |
| MV | 2（风格 + 角色） | 2（舞蹈参考） | 3（音轨） | 7 |
| 多镜头叙事 | 6（场景关键帧） | 1（风格参考） | 1（音乐） | 8 |
| 快速测试 | 1 | 0 | 0 | 1 |

> 黄金法则：每 2 秒视频对应 1 张参考图。少量高质量参考通常优于大量低质量参考。

### 常见 @ 引用错误

1. 上传后忘记 @ 引用 — 模型会忽略你的素材
2. 标记错误的媒体类型 — 上传的是图片却写 `@视频1`
3. 未指定角色 — 模型自行猜测各素材用途
4. 一个引用承担过多任务 — 拆分角色

## 核心提示词公式

```
[主体] + [动作] + [场景] + [镜头] + [光影/风格] + [音频/约束]
```

主体和主要动作放在最前面 — 靠前的语句设定镜头层次。单片段目标 40–110 词；生产级 60–100 词。

### 示例

```
一位年轻厨师（主体）正在用镊子精心摆盘（动作），
在米其林星级餐厅后厨，午夜时分（场景），
特写镜头从手部推至面部（镜头），
暖色钨丝灯照明，电影级 35mm 胶片颗粒感（风格），
无跳切，保持后厨背景统一（约束）。
```

### 6D 框架（稳定出品用）

1. **主体** — 谁或什么（建议单一主体）
2. **动作** — 在做什么（通俗语言，明确速度）
3. **场景边界** — 地点、时间、空间背景
4. **镜头** — 景别 + 运动方式 + 镜头感
5. **光影** — 一个精确的光影关键词胜过十个形容词
6. **时间** — 时长、节奏、节拍结构

## 镜头运动词汇表

使用精准术语获得精确控制：

| 运动方式 | 英文关键词 | 效果 |
|----------|-----------|------|
| 推向主体 | `slow push in` / `dolly in` | 特写强调，情感聚焦 |
| 远离主体 | `pull back` / `dolly out` | 环境揭示 |
| 水平滑动 | `tracking shot left/right` | 跟随主体 |
| 垂直升起 | `crane up` / `boom up` | 宏大感、尺度感 |
| 跟随主体 | `steadicam follow shot` | 动作、行走 |
| 环绕主体 | `orbit shot` / `360 arc` | 产品展示、主角亮相 |
| 快速摇摄 | `whip pan left/right` | 能量感、转场 |
| 固定机位 | `static shot` / `locked off camera` | 对话、观察 |
| 俯瞰视角 | `bird's eye view` / `top-down` | 定场、美食 |
| 仰拍视角 | `worm's eye view` / `low angle` | 力量感、压迫感 |
| 手持晃动 | `handheld camera` | 纪录片、真实感 |
| 平滑滑轨 | `gimbal shot` | 商业广告、精致感 |
| 焦点转移 | `rack focus to subject` | 情感聚焦 |
| 第一人称航拍 | `FPV continuous long take` | 沉浸感、动作 |

### 复合镜头运动

将复合运动拆分为顺序节拍 — Seedance 对顺序的理解优于同时：

```
起始：缓慢推轨建立场景。
然后：最后 2 秒向右轻柔横摇。
```

**错误写法：** "推轨同时横摇" — 把两个动作压在一句里。

### 景别 + 运动配对

| 景别 | 最佳搭配 | 避免 |
|------|---------|------|
| 远景 | 缓慢推轨或固定机位 | 快速横摇 |
| 中景 | 手持（亲切）或滑轨（精致） | — |
| 特写 | 轻微前推 | 横摇（突兀） |

## 视觉风格锚点

Seedance 对具体行业术语响应强烈。用专业锚点词替换空洞形容词：

| 避免 | 替换为 |
|------|--------|
| `电影感` | `固定特写，暖调主光，冷调轮廓光` |
| `震撼` | `大广角仰拍，渺小人影对抗风暴墙` |
| `唯美` | `湿瓷器上的珠光高光，柔和的窗户反射光` |

| `专业` | `洁净商业桌面，受控反光，无杂物` |

每次提示词叠加 2–3 个电影/锚点引用：
```
35mm 手持胶片摄影，自然颗粒 + DaVinci 工业级调色 + 冷调纪录片风格，自然光
```

## 场景模板

### 1. 产品广告

```
@图1（产品主角角度），@图2（生活场景角度），@图3（细节特写）。
@图1 置于极简展台上，纯黑背景。
柔光箱三点布光，产品边缘加轮廓光强调。
洁净商业桌面，受控反光，无杂物。
4K 清晰细节，滑轨级平滑运动。无跳切。
```

### 2. 角色叙事

```
@图1 是主角（身份锚点 — 精确保持）。
@图2 是场景设置。
[角色] 疲惫地走在走廊中，脚步渐缓，最终停在门口。
面部特写前推 — 深呼吸，表情从疲惫转为平静。
走廊壁灯暖色钨丝灯照明。
自然环境音：脚步声、呼吸声、门吱呀声。
```

### 3. 动作迁移

```
@图1（角色身份）表演 @视频1（动作参考）中的舞蹈。
场景：废弃仓库，光束中漂浮尘埃粒子。
镜头：大景别定场，随动作加强切换为中景跟拍。
破窗自然光入射，体积光效。
```

### 4. 多镜头叙事（分镜脚本格式）

```
[0:00–0:05] 远景 — 日出时火山岛航拍，缓慢前推。
[0:05–0:12] 中景 — 研究员从帐篷中走出，望向火山，焦点转至面部。
[0:12–0:20] 特写 — 眼眸中倒映远处火光，黄金时刻光线，手持微晃。
[0:20–0:27] 动作高潮 — 戏剧性喷发，火山灰翻滚，动态模糊，镜头震动。
[0:27–0:30] 定格/拉远 — 最终英雄帧，标题画面揭晓。

风格：BBC 行星地球纪录片风，自然光，无跳切。
```

### 5. 一镜到底

```
单镜头连续拍摄，无剪切。
镜头从巷口大景别开始，缓慢前推经过涂鸦墙面，
右跟一只流浪猫，升起展现黄昏天际线。
全程滑轨平滑。自然余光中霓虹灯逐一亮起。
时长：12 秒。
```

### 6. 音乐节拍匹配

```
@图1 @图2 @图3 @图4 @图5 @图6 @图7 —
按 @视频1 的节奏和整体韵律匹配关键帧位置，实现节拍同步剪辑。
角色动态更加活跃。
整体视觉风格更具梦幻感，视觉张力强烈。
根据音乐和视觉需求调整景别并增加光影变化。
```

### 7. 对话 / 唇形同步

```
@图1 为说话者。@音频1 为对话音轨。
@图1 正面特写，面对镜头。自然表情。
音素级唇形同步至 @音频1："[在此输入对话文本]"。
钨丝灯主光，柔和补光。固定机位，锁定镜头。
背景：科技风书房，浅景深。
```

## 多镜头序列工作流

适用于跨多个片段的项目：

1. **定义故事目标** — 最终结局、节拍、场景分组
2. **设定片段预算** — 每个节拍放入哪个片段
3. **锚定一致性** — 每个片段使用相同角色引用 (`@图1`)
4. **跟踪规范状态** — 已确认的素材定义现实；被拒素材排除在外
5. **延续规则** — 写下一个片段前回顾实际结束帧
6. **场景边界** — 每个场景切换时从规范引用重新开始

### 序列不变量
- 所有片段中 `@图1` 始终指向同一角色
- 仅描述与上一片段不同的内容
- 延长深度计数器在场景边界处归零
- 绝不将未来节拍泄露进当前提示词
- 每次确认生成后更新连续性状态

## 反空洞检查清单

交付提示词前，验证：

- [ ] 一个可见节拍（我们实际看到什么发生）
- [ ] 一个动机明确的镜头运动（为什么动）
- [ ] 一个动机明确的光源（光从哪里来）
- [ ] 声音意图（我们听到什么）
- [ ] 导演一致性（一个意图；镜头、光影、表演都为它服务）
- [ ] 无空洞词汇：将 `电影感`、`震撼`、`唯美`、`动感`、`专业` 替换为具体制作语言
- [ ] 每个主要短语通过可见性测试（能被镜头看到、被测光表量到、在混音中听到、或被观察为运动）
- [ ] 引用标签精确保留 — 绝不修改 `@图1` 语法
- [ ] 提示词长度 40–110 词（单片段）或 60–100 词（出品级）

## 故障排除

| 问题 | 根本原因 | 解决方案 |
|------|---------|----------|
| 角色身份漂移 | 场景变化过多 | 每次生成一个环境，每次提示词用相同 @图1 |
| 输出混乱 | 使用了"快节奏"等模糊词 | 替换为 `平滑节奏`，每次只让一个元素运动 |
| 运动模糊不清 | 速度描述模糊 | 具体说明：`以 0.5 倍速行走` 而非 `慢慢走` |
| 唇形不同步 | 对话文本不明确 | 使用方括号：`[对话："精确文本"]` |
| 镜头太抖 | 未指定稳定方式 | 加上 `滑轨平滑` 或 `稳定` |
| 末尾画质下降 | 时长接近上限 | 即使最大时长更高，也控制在 10 秒以内 |
| 抖动 / 闪烁 | 使用了"快"这个词 | 避免"快"；保持单一元素正常速度运动 |
| 引用被忽略 | 上传但未 @ 标记 | 检查提示词中每个素材都写了 @图1、@视频1 等 |
| 人脸检测拦截 | 上传了逼真人脸 | 使用风格化/插画参考；通过第三方 API 绕过 |
| 画面出现双胞胎 | 多主体场景过于复杂 | 每场景一个主体 |

### 重拍协议

当生成结果不理想时：

1. **保留** — 足够好，可以接受
2. **后期修复** — 可通过剪辑修复的小问题
3. **编辑模式** — 使用 Seedance 编辑模式做针对性修改
4. **重试** — 相同提示词，换不同随机种子
5. **重写** — 仅修改一个变量（一个镜头词、一个光源、一个约束）
   - 绝不要重写整个提示词；每次只改一处
   - 在判断提示词无效前先生成 3–5 次（AI 输出是随机的）

## 专业提示

1. **片段控制在 10 秒以内** — 即使上限更高，末尾几秒画质也会明显下降
2. **参考图是一致性的关键** — 每个片段用同一张面部参考来锁角色
3. **善用多输入系统** — 参考图 + 音频 + 文本一起用，不要只用文本
4. **用 Dreamina 做测试** — 每日免费积分，不要付费做实验
5. **小步迭代** — 改一个词或换一张参考图，不要全盘重写
6. **"画面切换到..."** 做单片段多场景视频
7. **避免使用"快"这个词** — 会导致画面抖动。如需节奏最多让一个元素快
8. **镜头运动和主体运动分开描述** — 避免画面晃动
9. **使用高分辨率参考素材** — 输入 2K 或 4K 图片。糊进糊出
10. **原生音频是特性而非副产物** — 让 Seedance 自行生成同步音频，不要后期添加
11. **每场景一个主体** — 多主体 = 结果不一致
12. **时长设置 = 新生成部分的时长** — 而非总时长
