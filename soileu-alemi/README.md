# Сөйлеу әлемі
Логопедиялық ойындар сайты (6 жас). Статикалық, сервер қажет емес.

- Ашу: `soileu-alemi.html` (бір файл) немесе `index.html`.
- Камера/микрофон үшін https:// немесе localhost керек: `python3 -m http.server 8000` → http://localhost:8000
- Сөйлеуді тану үшін Chrome/Edge және интернет ұсынылады.
- Өзгерту: `data.js` (ойын мазмұны), `app.js`, `media.js`, `styles.css`; сосын `./build.sh`.
